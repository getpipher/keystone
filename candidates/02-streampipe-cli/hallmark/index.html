$streampipe — stream parsing for log and event pipelines.

One static binary. Reads lines from files, pipes, sockets, and kubectl logs. Parses each line into a structured event, filters it, writes JSON to the next stage. No agent, no daemon, no config file.

Install

shell$brew install streampipe/tap/streampipe
$curl -fsSL https://get.streampipe.dev | sh
$go install github.com/streampipe/cli/cmd/streampipe@latest
$streampipe --version▮
streampipe 0.9.2

One pipeline

5xx paths from an nginx access log, as JSON$streampipe parse access.log --format nginx --filter status=5xx | jq .path

Every stage is a flag. --format picks the parser, --filter keeps the events you name, and the output is JSON lines on stdout — so the next tool in the pipe doesn’t care where the lines came from.
