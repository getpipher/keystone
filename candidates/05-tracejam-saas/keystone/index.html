Capture without agents.

One binary speaks OpenTelemetry on :4317. Point your SDKs at it and every service shows up in the same trace — no sidecars, no per-team collectors.

$ brew install tracejam
$ tracejam capture --otlp :4317
  listening on :4317 · otlp/grpc + http

Query traces like tables.

Spans land in a queryable store. Ask in one line what used to take a dashboard, three services, and a hunch.

$ tracejam query 'latency > 200ms && service = checkout'
  212 spans · 3 services · 1 root cause

Find the span that regressed.

Diffs are first-class: pick two deploys and Tracejam lines up every changed span — new, gone, slower — side by side.

$ tracejam diff v2.4.1 v2.4.2 --service checkout
  + payments.auth      41ms → 118ms   (regressed)
  − cache.warm        removed
  = db.orders          unchanged
